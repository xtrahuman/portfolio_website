Four ways to show the same work

Each one is a working prototype built on the same projects and contact details. Open them, click around, and pick the direction (or mix parts of several).

Safest pick

A fast, conventional page anyone can skim in ten seconds, with a command palette for keyboard users.

Why recruiters like it
Works for every recruiter, on every phone. Projects are on screen from the first second.
Watch out for
Less memorable on its own, so polish and the palette carry the "developer" signal.

Code editor

The portfolio as a code editor. Each page is a file; the README opens rendered so non-developers still see a normal page.

Why recruiters like it
Says "developer" at a glance. Tech recruiters know this layout from every screen share.
Watch out for
Raw code can feel dense. Keep rendered previews as the default view.
